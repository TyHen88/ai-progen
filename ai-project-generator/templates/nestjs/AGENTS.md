# AGENTS.md — templates/nestjs

## Purpose
**NestJS Template** — Scaffolding for a production-ready NestJS TypeScript backend API.

## Includes
- NestJS with TypeScript
- TypeORM with PostgreSQL
- JWT authentication guards
- Swagger API documentation
- Docker support
- Jest test setup

## Agent Guidelines
- Follow NestJS module structure (module/controller/service/entity).
- Use DTOs with `class-validator` decorators.
