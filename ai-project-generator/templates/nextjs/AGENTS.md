# AGENTS.md — templates/nextjs

## Purpose
**Next.js Template** — Scaffolding for a production-ready Next.js TypeScript frontend.

## Includes
- Next.js 14+ with App Router
- TypeScript configuration
- Tailwind CSS setup
- ESLint + Prettier
- Docker support
- CI/CD GitHub Actions workflow

## Variables
| Variable | Description |
|----------|-------------|
| `PROJECT_NAME` | Application name |
| `DESCRIPTION` | Project description |
| `API_URL` | Backend API base URL |

## Agent Guidelines
- Use App Router by default (not Pages Router).
- Include proper SEO metadata in layout files.
