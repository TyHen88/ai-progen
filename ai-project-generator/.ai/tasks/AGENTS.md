# Task Management

Every feature begins with a task.

---

Task Format

TASK-001

Title

Description

Priority

Dependencies

Acceptance Criteria

Implementation Plan

Progress

Completed Files

Review Notes

---

Workflow

TODO

↓

IN PROGRESS

↓

REVIEW

↓

TESTING

↓

DONE

---

Task Rules

One task

One feature

One responsibility

Keep tasks small.

Recommended duration

1–4 hours.
