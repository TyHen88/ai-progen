# AGENTS.md — docs/decisions

## Purpose
**Architecture Decision Records (ADRs)** — Documents significant architectural and technical decisions made during the project, along with their context and rationale.

## ADR Format
Each ADR file should follow this structure:
- **Title**: Short descriptive name
- **Status**: Proposed / Accepted / Deprecated / Superseded
- **Context**: Problem and constraints
- **Decision**: The chosen solution
- **Consequences**: Trade-offs and implications

## Agent Guidelines
- Create a new ADR for every major technical decision.
- Never delete old ADRs — mark them as Deprecated/Superseded instead.
- Reference ADRs from architecture docs when relevant.
